01 // PROJECT OVERVIEW

Apna Mart

Apna Mart is Evolix’s customer-facing retail product connected with Apna Galla. The owner describes a flow in which a shop using Apna Galla can go live on Apna Mart and receive customer orders.

02 // PUBLIC EXPERIENCE

What the screenshots show

The public web preview introduces nearby shops and customer ordering. At capture time it reported no active service areas, so no shop listings or customer orders were shown. The gallery records this actual public state after the hosting service finished waking up.

03 // PROJECT AVAILABILITY

Website & product status

The public preview is reachable at apna-mart.in, with service-area activation still pending at capture time. The owner has described the Play Store app as upcoming; this page does not present it as an already released Android app.
